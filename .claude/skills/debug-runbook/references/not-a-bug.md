# Bug or policy?

The customer-facing rules live in `help/`; read the page before touching code.

| The report is about | Read |
|---|---|
| a refund amount, cancelling, refunds after the show | `help/refund-policy.md` |
| the price, the service fee, VAT | `help/booking-and-fees.md` |
| early-bird or group discounts, discount codes | `help/early-bird-and-discounts.md` |
| an AI agent, an API key, a tool that refuses | `help/ai-agents-and-api-keys.md` |

The three reports that are almost always policy:
- **"I didn't get all my money back."** The service fee is not refundable and the refund fee (2%, at least €0.50) is kept. Recompute both before calling it a bug.
- **"My refund is zero."** Refunds close when the event starts.
- **"The early-bird price disappeared."** It ends exactly 30 days before the event.
